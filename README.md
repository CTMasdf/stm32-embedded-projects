# STM32 Embedded Systems Portfolio

This repository contains a collection of STM32-based embedded system projects developed using STM32CubeIDE and HAL Driver.

The goal of this project series is to build a solid foundation in embedded systems, including GPIO control, interrupts, real-time systems, and state machine design.

---

## 📌 Project Overview

| Project | Title | Description |
|--------|------|-------------|
| Project01 | FreeRTOS LED MultiTask | Basic RTOS task scheduling with LED control |
| Project02 | Push Button Interrupt (EXTI) | GPIO interrupt-based button control system |
| Project03 | Slide Switch Mode Controller | State machine-based system mode control |

---

## 🎯 Core Learning Goals

Through these projects, I focused on building practical embedded system skills:

- GPIO input/output control
- External Interrupt (EXTI) handling
- FreeRTOS multitasking concepts
- State Machine-based system design
- Non-blocking timing using HAL_GetTick()
- Modular firmware structure design

---

## 🧠 System Design Philosophy

This project series is designed to move from simple control logic to system-level embedded design:
Event-based Control (Project02)
↓
State-based Control (Project03)
↓
Real-time Multitasking (Project01 / FreeRTOS)
↓
Advanced Embedded System Design
